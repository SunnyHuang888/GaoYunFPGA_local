# FPGA 音频系统模块总览

更新时间：2026-09-19  
架构图：`离线文档/gaoyun-architecture-20260919.jpg`  
接口基线：`fpga-electronic-piano/code/docs/模块接口规范.md` v1.2

> 本文根据架构图和 `fpga-electronic-piano/code/docs` 下的项目文档整理。架构图表示目标系统全链路；文中“已验证”表示已有仿真、综合、布局布线或上板证据，“计划中”表示已定义但尚未完成正式验收。

## 1. 系统总览

系统分为三层：

1. **上位机与开发工具链**：Python 上位机、Python 参考模型、音频分析工具、仿真与 Gowin EDA。
2. **FPGA 实时数字处理链**：输入适配、统一演奏事件、事件 FIFO、声部管理、DDS/波表、ADSR、混音与效果器、PCM 和 I2S。
3. **板级音频输出链**：Tang Mega 60K + NEO Dock、PT8211 DAC、NS4263 功放和扬声器/耳机。

主数据流：

```text
输入适配
  -> 统一演奏事件
  -> 事件 FIFO
  -> 声部管理
  -> DDS / 波表
  -> ADSR
  -> 混音与效果器
  -> 24 位 PCM
  -> I2S 发送器
  -> PT8211 DAC
  -> NS4263 功放
  -> 扬声器或耳机
```

## 2. 上位机与开发工具链

| 模块 | 模块定义 | 输出成果 | 主要接口 |
|---|---|---|---|
| Python 上位机 | 连接 FPGA，显示状态、错误计数和测试日志 | 串口状态解析、终端显示、CSV 日志、异常处理 | 输入 UART 状态文本；输出状态显示和 CSV |
| Python DDS 参考模型 | 定义频率、相位、波形和音频数学行为 | `dds_model.py`、FCW 计算、频率测试 | 输入音符、频率、采样率、相位；输出 FCW、波形样本和误差 |
| 波表/FCW 生成器 | 生成波表、频率控制字和测试向量 | 波表文件、FCW 表、`manifest.json`、测试向量 | 输入采样率、深度、位宽；输出 ROM 初始化数据 |
| 音频分析工具 | 分析 WAV、频谱、SINAD、THD 和延迟 | WAV、频谱图、音频分析报告 | 输入 PCM/WAV；输出频谱、频率、噪声和失真指标 |
| 仿真与 Gowin EDA | 完成 RTL 仿真、综合、布局布线、时序和码流生成 | Testbench、仿真报告、综合报告、PnR 报告、`.fs` 码流 | 输入 RTL、TB、CST、SDC；输出 PASS/FAIL、资源、时序和码流 |
| 上位机串口工具 | 读取 FPGA UART 状态通道 | 串口解析、状态终端、CSV 记录 | 输入 UART 文本行；输出状态字段和错误统计 |

最终交付物包括正式码流、源码冻结标签、竞赛报告、演示视频、答辩材料以及操作说明。

## 3. FPGA 实时数字处理链

### 3.1 时钟、复位与采样节拍

| 项目 | 定义 |
|---|---|
| 模块职责 | 产生统一 `sys_clk`、同步复位和 48 kHz `sample_tick` |
| 输出成果 | 时钟方案、复位同步器、时序约束、时钟分析报告 |
| 输入接口 | `clk`、外部低有效 `rst_n` |
| 输出接口 | `sys_clk`、`sys_rst_n`、单周期 `sample_tick` |
| 规则 | 音频算法使用 `sample_tick` 作为 `sys_clk` 下的时钟使能，不把它作为独立时钟 |
| 状态 | T019 已完成，已有仿真验证 |

固定约束：内部采用单一 `sys_clk`；外部复位低有效，可异步拉低、同步释放；每个独立时钟域使用本域复位同步器。

### 3.2 输入适配

#### 板载按键适配

| 项目 | 定义 |
|---|---|
| 模块职责 | 对异步按键进行同步、去抖，并转换为演奏事件 |
| 输出成果 | `button_debouncer.sv`、`button_event_converter.sv`、自检 TB |
| 输入接口 | `button_n_async` 或顶层 `key_n[]` |
| 输出接口 | `performance_event_t`，配合 `event_valid/event_ready` |
| 当前状态 | 已验证两键链路：`AB13` 对应 A4，`Y12` 对应 C5 |

#### MIDI 输入适配

| 项目 | 定义 |
|---|---|
| 模块职责 | 接收 MIDI UART 字节流，解析 Note、Velocity、Pitch Bend 和 Control Change |
| 输出成果 | UART 接收器、MIDI 解析器、MIDI 到统一事件转换器 |
| 输入接口 | 异步串行 MIDI，标准速率 31.25 kbaud |
| 输出接口 | 64 位 `performance_event_t` |
| 规则 | Note On 且 Velocity 为 0 时转换为 Note Off；连续控制限速并合并 |
| 状态 | 方案已选定，但键盘型号、电平和最终接线仍待核实 |

5 V 外部信号不得直接连接 3.3 V FPGA GPIO，必须确认电平或增加电平转换。

### 3.3 统一演奏事件

| 项目 | 定义 |
|---|---|
| 模块职责 | 将按键、MIDI 或传感器输入统一为音频核心事件 |
| 输出成果 | `audio_defs_pkg.sv` 中的事件类型和构造函数、事件转换模块、测试桩 |
| 输入接口 | 输入适配器产生的演奏动作 |
| 输出接口 | 64 位 `performance_event_t` |
| 握手接口 | `event_valid`、`event_ready`、`event_data` |
| 状态 | T014 已完成，统一事件包为唯一事件定义来源 |

事件结构：

```systemverilog
typedef struct packed {
    logic [2:0]  event_type;
    logic [3:0]  source_id;
    logic [3:0]  channel;
    logic [6:0]  note_number;
    logic [9:0]  velocity;
    logic [9:0]  expression;
    logic [7:0]  control_id;
    logic [11:0] control_value;
    logic [5:0]  reserved;
} performance_event_t;
```

事件类型包括 Note On、Note Off、Aftertouch、Pitch Bend、Control Change 和 All Notes Off。

### 3.4 事件 FIFO

| 项目 | 定义 |
|---|---|
| 模块职责 | 缓存输入事件，隔离输入速率和音频采样处理速率 |
| 输出成果 | 深度 32 的事件 FIFO、反压逻辑、溢出计数器 |
| 输入接口 | `event_valid`、`event_ready`、`event_data` |
| 输出接口 | 送往声部管理器的事件流 |
| 状态接口 | 当前水位、最高水位、溢出次数 |
| 规则 | FIFO 满时反压，不允许静默丢弃 Note Off |

### 3.5 声部管理

| 项目 | 定义 |
|---|---|
| 模块职责 | 将 Note 事件分配给空闲声部，处理重复音、释放和声部抢占 |
| 输出成果 | `voice_manager`、声部分配 Python 模型、随机事件测试 |
| 输入接口 | 演奏事件流、`sample_tick`、复位 |
| 输出接口 | `voice_note[]`、`voice_gate[]`、`active_voice_count` |
| 当前策略 | 优先使用空闲声部；无空闲时抢占最旧声部；同音重复时重新触发 |
| 目标 | 保底 4 复音，后续按资源预算扩展 |
| 状态 | T010 设计中，正式 4 声部尚未完成 |

建议接口：

```systemverilog
input  logic        clk;
input  logic        rst_n;
input  logic [63:0] event_in;
input  logic        event_valid;

output logic [6:0]  voice_note [NUM_VOICES-1:0];
output logic        voice_gate [NUM_VOICES-1:0];
output logic [3:0]  active_voice_count;
```

### 3.6 音高查表

| 项目 | 定义 |
|---|---|
| 模块职责 | 将 MIDI 音符号转换为 DDS 频率控制字或相位增量 |
| 输出成果 | `note_pitch.sv`、音高查表、音高误差测试 |
| 输入接口 | `note_number`、Pitch Bend 等音高控制量 |
| 输出接口 | `phase_step` / FCW |
| 约束 | 使用明确的定点格式，不使用无说明的浮点运算 |
| 状态 | 已有占位实现，正式算法验收仍由 M1 负责 |

### 3.7 DDS 与波表振荡器

| 项目 | 定义 |
|---|---|
| 模块职责 | 通过相位累加器和波表产生逐采样音频波形 |
| 输出成果 | `simple_voice.sv`、DDS 参考模型、正弦波表 ROM、FCW 生成脚本 |
| 输入接口 | `phase_step`、`voice_gate`、`sample_tick`、复位 |
| 输出接口 | 单声部有符号 PCM 样本 |
| 内部状态 | 相位累加器、当前波形采样值 |
| 状态 | 单声部占位链路已验证，正式 DDS RTL 对应 T004 |

单声部输出峰值固定为 `2097152`，即 24 位 PCM 满幅的四分之一。

### 3.8 ADSR 包络

| 项目 | 定义 |
|---|---|
| 模块职责 | 控制声部 Attack、Decay、Sustain 和 Release |
| 输出成果 | ADSR Python 参考模型、RTL 包络、边界测试 |
| 输入接口 | Note On、Note Off、Velocity、Expression、`sample_tick` |
| 输出接口 | 声部幅度包络值和门控状态 |
| 目标 | 消除 Note On 时从 0 直接跳到满幅造成的咔哒声 |
| 状态 | T009 尚未正式实现 |

包络时间常数、曲线和定点表示由 M1 定义；流水线、资源和时序实现由 M2 协助。

### 3.9 混音与饱和限幅

| 项目 | 定义 |
|---|---|
| 模块职责 | 对多个声部 PCM 进行宽位累加和饱和限幅 |
| 输出成果 | `mixer.py`、混音 RTL、边界测试向量、`clip_count` |
| 输入接口 | 多路 24 位有符号声部 PCM |
| 输出接口 | 24 位有符号 `pcm_left`、`pcm_right` |
| 累加位宽 | 至少 32 位 |
| 限幅规则 | 超出 `[-8388608, 8388607]` 时饱和，不允许回绕 |
| 状态 | T023 设计中 |

旧版 T023 文档曾提到 26 位中间结果，但最新接口规范 v1.2 明确要求累加器至少 32 位，以 v1.2 为准。

### 3.10 延迟效果器

| 项目 | 定义 |
|---|---|
| 模块职责 | 对混音后的 PCM 加入可调延迟、干声、湿声和反馈 |
| 输出成果 | 延迟效果器 Python 模型、BSRAM 循环缓冲 RTL、参数测试 |
| 输入接口 | 24 位 PCM、`delay_time`、`dry_gain`、`wet_gain`、`feedback` |
| 输出接口 | 处理后的 24 位 PCM |
| 存储结构 | 48 kHz、500 ms 约需 24000 个样本，建议使用 BSRAM |
| 规则 | 反馈小于 1，参数切换平滑，输出饱和 |
| 状态 | T028 计划 W5 实现 |

### 3.11 PCM 音频接口

| 项目 | 固定定义 |
|---|---|
| 输入来源 | 混音器或效果器 |
| 输出信号 | `pcm_left`、`pcm_right` |
| 数据格式 | 24 位有符号二进制补码 |
| 握手 | `pcm_valid`、`pcm_ready` |
| 采样节拍 | 每个 `sample_tick` 最多交付一组左右声道 |
| 缓存要求 | I2S 串行发送期间不能读取正在变化的算法输出 |

接口定义：

```systemverilog
output logic signed [23:0] pcm_left;
output logic signed [23:0] pcm_right;
output logic               pcm_valid;
input  logic               pcm_ready;
```

### 3.12 I2S 音频串行发送

| 项目 | 固定定义 |
|---|---|
| 模块职责 | 将并行 PCM 转换为 PT8211 所需的串行音频数据 |
| 输出成果 | I2S 发送器、解码 TB、时序约束、上板验证 |
| 输入接口 | 24 位 `pcm_left/right`、`pcm_valid/ready`、`sys_clk` |
| 输出接口 | `i2s_bclk`、`i2s_lrck`、`i2s_din` |
| 采样率 | 48 kHz |
| BCLK | 3.072 MHz |
| 帧结构 | 双声道、每声道 32 位、每帧 64 BCLK |
| 有效数据 | 16 位 |
| 数据格式 | LSBJ，16 位数据右对齐，MSB first |
| 转换 | 24 位 PCM 发送前进行舍入和饱和转换为 16 位 |
| 状态 | 单声部 I2S 输出链路已完成上板验证 |

板级端口：

| FPGA 信号 | FPGA 引脚 |
|---|---|
| `i2s_bclk` | `Y17` |
| `i2s_lrck` | `AB17` |
| `i2s_din` | `AA16` |
| `pa_en` | `AB16` |

### 3.13 UART 状态通道

| 项目 | 定义 |
|---|---|
| 模块职责 | 输出系统状态、错误计数和性能信息 |
| 输出成果 | UART TX、状态计数器、固定格式状态行 |
| 输入接口 | 各子系统状态信号 |
| 输出接口 | `uart_tx` |
| 状态字段 | `active_voice_count`、`clip_count`、`event_fifo_level`、`event_fifo_overflow`、`audio_underrun`、`max_processing_cycles` |
| 责任 | FPGA 侧由 M2 负责；上位机解析由 M3 负责 |
| 状态 | T025 尚未正式完成 |

### 3.14 复音数自证测试模式

| 项目 | 定义 |
|---|---|
| 模块职责 | 产生固定频率、固定声部数的纯正弦，证明实时复音能力 |
| 输出成果 | 测试模式 RTL、固定 FCW、参考 PCM、FFT 频谱验证 |
| 输入接口 | `test_mode_enable`，可由硬件开关或 UART 命令控制 |
| 输出接口 | N 路固定频率声部、`active_voice_count`、`clip_count` |
| 测试频率 | 示例为 200 Hz、400 Hz、600 Hz、800 Hz |
| 行为 | 测试模式屏蔽按键和 MIDI 输入，强制激活 N 个声部 |
| 状态 | T052 已定义，尚未完成正式验收 |

## 4. 板级音频输出链

| 模块 | 模块定义 | 输出成果 | 接口 |
|---|---|---|---|
| Tang Mega 60K + NEO Dock | FPGA 实时处理平台和外设载体 | Gowin 工程、CST、SDC、码流 | 50 MHz 时钟、复位、GPIO、I2S、UART |
| PT8211 DAC | 将 FPGA I2S 数字音频转换为模拟音频 | I2S 时序验证、DAC 输出测量 | `BCK`、`WS/LRCK`、`DIN`、模拟左右声道 |
| NS4263 功放 | 对 DAC 模拟音频进行功率放大 | 功放使能时序、音频链路测量 | 模拟音频输入、`PA_EN` |
| 无源扬声器/耳机 | 最终声音输出和听感验证 | 演示音频、实测数据、视频素材 | 功放模拟输出 |

音频输出路径：

```text
FPGA i2s_bclk / i2s_lrck / i2s_din
  -> PT8211 DAC
  -> NS4263 功放
  -> 无源扬声器或耳机
```

`pa_en` 为低有效：`0` 表示打开功放，`1` 表示关闭功放；上电初始化阶段必须保持为 `1`，避免爆音。

## 5. 系统级接口总表

| 接口 | 宽度/格式 | 连接模块 |
|---|---|---|
| `sys_clk` | 单系统时钟 | 所有 FPGA 模块 |
| `rst_n` / `sys_rst_n` | 低有效复位 | 顶层和各时序模块 |
| `sample_tick` | 48 kHz 单周期使能 | 音频核心、ADSR、DDS、混音、效果器 |
| `performance_event_t` | 64 位 | 输入适配、事件 FIFO、声部管理 |
| `event_valid` / `event_ready` | 标准 valid-ready 握手 | 输入适配与事件 FIFO |
| `pcm_left/right` | 24 位有符号 PCM | 音频核心与 I2S 发送器 |
| `pcm_valid` / `pcm_ready` | 标准 valid-ready 握手 | 音频核心与 I2S 发送器 |
| `i2s_bclk` | 3.072 MHz | FPGA 到 PT8211 |
| `i2s_lrck` | 48 kHz | FPGA 到 PT8211 |
| `i2s_din` | 16 位有效数据，LSBJ | FPGA 到 PT8211 |
| `pa_en` | 低有效功放使能 | FPGA 到 NS4263 |
| `uart_tx` | UART 文本状态流 | FPGA 到上位机 |
| 状态计数器 | 多个饱和计数值 | 各子模块到 UART 状态通道 |
